# Setup Guide\n\n## Prerequisites\n\n- Node.js 18+\n- npm 9+\n- API keys for Claude, Perplexity, and GitHub\n\n## Step 1: Get API Keys\n\n### Claude (Anthropic)\n1. Visit https://console.anthropic.com\n2. Sign up or login\n3. Create an API key\n4. Copy it to `.env` as `CLAUDE_API_KEY`\n\n### Perplexity\n1. Visit https://www.perplexity.ai/api\n2. Sign up and get API access\n3. Create API key\n4. Copy it to `.env` as `PERPLEXITY_API_KEY`\n\n### GitHub\n1. Go to https://github.com/settings/tokens\n2. Click \"Generate new token (classic)\"\n3. Select scopes: `repo`, `gist`\n4. Copy to `.env` as `GITHUB_TOKEN`\n\n## Step 2: Install & Configure\n\n```bash\n# Install\nnpm ci\n\n# Configure\ncp .env.example .env\n# Edit .env with your API keys\n```\n\n## Step 3: Run\n\n```bash\n# Start server\nnpm start\n\n# Server runs on http://localhost:3000\n```\n\n## Step 4: Test\n\n```bash\n# Test Claude\ncurl -X POST http://localhost:3000/api/claude \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"prompt\": \"Hello Claude\"}'\n\n# Test Perplexity\ncurl -X POST http://localhost:3000/api/perplexity \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"query\": \"Hello Perplexity\"}'\n\n# Test Smart Router\ncurl -X POST http://localhost:3000/api/route \\\n  -H \"Content-Type: application/json\" \\\n  -d '{\"task_type\": \"research\", \"prompt\": \"AI trends\"}'\n```\n\n## Troubleshooting\n\n**\"API key not found\"**\n- Check `.env` file exists\n- Verify API key values\n- Restart server after changes\n\n**\"Invalid API key\"**\n- Double-check key is correct\n- Verify key has proper permissions\n- Check key hasn't expired\n\n**Port already in use**\n- Change PORT in `.env`: `PORT=3001`\n- Or kill process using port 3000\n
